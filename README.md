# ConnectX Telecom Customer Churn Analysis

## Project Overview
This project analyzes customer churn data for a telecom company using Microsoft Power BI.

## Objectives
- Analyze customer churn rate.
- Understand age and gender distribution.
- Explore customer tenure.
- Analyze contract types and payment methods.
- Identify relationships between tenure and total charges.
- Understand customer revenue distribution.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Exploratory Data Analysis

## Dashboard Features
- Customer KPI cards
- Churn analysis
- Customer demographics
- Contract and payment analysis
- Revenue analysis
